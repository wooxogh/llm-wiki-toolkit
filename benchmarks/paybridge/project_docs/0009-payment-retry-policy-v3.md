# 0009. 결제 재시도 정책 환원 (v3)

**Status:** Accepted
**Supersedes:** 0004
**Date:** 2026-06-05
**Owner:** 박서연 (결제팀)

## Context
0004에서 재시도 횟수를 3회로 늘린 이후, 일부 리전에서 재시도 간 중복 승인 이슈가
접수되었다(2026-05 월간 보고서 참고). 원인 분석 결과 3회 재시도 시 idempotency key
만료 시간과 충돌하는 것으로 확인되었다.

## Decision
결제 실패 시 재시도 횟수를 다시 2회로 환원한다. 향후 idempotency key 만료 시간을
늘리는 별도 개선이 완료되면 재시도 횟수 상향을 재검토한다.

## Consequences
- 긍정적: 중복 승인 이슈 해소
- 부정적: 통신 불안정 구간에서의 결제 성공률은 다시 소폭 하락 가능
