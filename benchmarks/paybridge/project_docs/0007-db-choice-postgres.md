# 0007. 주 데이터베이스를 PostgreSQL로 전환

**Status:** Accepted
**Supersedes:** 0003
**Date:** 2026-04-18
**Owner:** 이지훈 (백엔드 리드)

## Context
0003에서 MySQL을 채택했으나, 엔터프라이즈 가맹점 대상 정산 리포트 기능이 복잡해지면서
윈도우 함수·CTE 등 고급 쿼리 기능이 필요해졌다. (2026-04 월간 보고서의 엔터프라이즈 매출 확대 참고)

## Decision
주 데이터베이스를 PostgreSQL 15로 전환한다. 기존 MySQL 데이터는 3개월간 병행 운영 후 마이그레이션한다.

## Consequences
- 긍정적: 복잡한 정산 쿼리 처리 가능
- 부정적: 마이그레이션 기간 중 이중 운영 부담
