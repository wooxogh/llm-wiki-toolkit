# 0004. 결제 재시도 정책 변경 (v2)

**Status:** Accepted
**Supersedes:** 0002
**Date:** 2026-02-11
**Owner:** 박서연 (결제팀)

## Context
0002에서 정한 재시도 2회 기준으로는 일부 통신 불안정 구간에서 결제 실패가 반복되고 있다.
(2026-02 월간 보고서의 가맹점 이탈 증가 지표 참고)

## Decision
결제 실패 시 최대 3회까지 자동 재시도하도록 변경한다.

## Consequences
- 긍정적: 결제 성공률 추가 개선 예상
- 부정적: 재시도 횟수 증가로 인한 응답 지연 가능성
